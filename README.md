# Features

•	Add Tasks: Quickly add new tasks to your list with a title and optional description.

•	Delete Tasks: Remove tasks that are no longer needed.

•	Mark as Completed: Keep track of completed tasks and focus on what’s left to do.
 
•	Persistent Storage: All tasks are stored locally using Core Data, ensuring your to-do list is available even when the app is closed.

# Purpose

### This project aims to provide a hands-on experience in using Core Data for data management in iOS applications. It is intended to help developers understand:

•	Setting up and configuring Core Data in a UIKit-based iOS app.

•	Managing data entities and relationships.

•	Performing CRUD (Create, Read, Update, Delete) operations.
